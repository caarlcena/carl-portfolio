# Carl Louise Cena — Portfolio

A modern, responsive single-page portfolio built from my QA resume.

## Stack
- HTML5
- TailwindCSS (via CDN) — no build step
- Vanilla JavaScript
- Google Fonts (Inter + JetBrains Mono)

## Run locally
Just open `index.html` in any modern browser, or serve it:

```bash
# Python
python -m http.server 8080
# then visit http://localhost:8080
```

## Deploy
Drop the folder into Netlify, Vercel, GitHub Pages, or Cloudflare Pages.
It's already 100% static.

## Customize
- **Content:** edit `index.html` directly (each section is clearly labeled).
- **Theme:** change `accent` colors inside the `tailwind.config` block in `index.html`.
- **Animations & active nav:** see `script.js`.
- **Component styles:** `styles.css`.
